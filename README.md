# Учебные мини-проекты / Frontend Mini-Projects

Коллекция практических работ по фронтенд-разработке. В репозитории собраны независимые проекты, созданные в процессе обучения и отработки навыков верстки по реальным макетам.

## Используемые технологии

- **HTML5** — семантическая структура страниц.
- **Tailwind CSS** — utility-first подход к стилизации (настройка через `input.css`, кастомные `@theme` и `@utility`).
- **JavaScript** — интерактивность и логика (в планах).
- **Git** — контроль версий.

## Проекты

### [Project-1: Tailwind CSS Basics](./project-1-TailwindCSS)
Верстка макета из Figma с упором на базовые возможности Tailwind: работу с сетками, отступами, типографикой и адаптивностью.

### [Project-2: Web Agency Landing Page](./project-2-TailwindCSS)
Верстка более сложного макета Web Agency из Figma. В проекте используются продвинутые настройки Tailwind (экспорт цветов, кастомные градиенты и составные текстовые стили через `@theme` и `@utility`).
